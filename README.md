# meu-portifolio

Repositório criado para organizar minha jornada de estudos em Tecnologia da Informação, reunindo minha apresentação profissional, o material das disciplinas cursadas e os projetos e certificados desenvolvidos ao longo do curso.

## Estrutura

- `apresentacao_e_perfil/` — perfil pessoal, biografia acadêmica e contato
- `disciplinas_atuais/` — anotações, resumos e atividades das disciplinas do semestre
- `projetos_e_certificados/` — projetos práticos e certificados obtidos

## Convenções

- Pastas numeradas na raiz para manter a ordem lógica
- Nomes sem acentos e sem espaços, usando `_` entre palavras
- Cada disciplina possui sua própria subpasta dentro de `02_Disciplinas_Atuais/`
